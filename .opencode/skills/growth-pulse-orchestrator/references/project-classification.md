# Project Classification

Classify each task into one or more categories. A project can belong to multiple categories.

- marketing website: multi-page brand / service presence, conversion via contact / quote
- landing page: single-page campaign, hero + proof + CTA, fast load, SEO / tracking
- business website: services, about, contact, local SEO
- portfolio: case studies, imagery, credibility
- SaaS/product interface: authenticated app UI, onboarding, billing, settings
- dashboard: data display, charts, tables, filters, roles
- e-commerce: catalog, cart, checkout, payments, orders
- booking system: availability, reservations, confirmations, reminders
- web application: interactive CRUD, state, API-backed flows
- API/backend: endpoints, auth, validation, DB, integrations
- automation: scripts, webhooks, scheduled jobs
- redesign: visual / UX overhaul of existing site, preserve SEO + functionality
- bug fix: reproduce, isolate, fix, regression-test
- performance optimization: Core Web Vitals, bundle, images, caching
- SEO: metadata, sitemap, robots, structured data, canonical, internal links
- accessibility: keyboard, focus, contrast, semantics, ARIA, reduced motion
- security: auth, input validation, headers, secrets, dependencies
- deployment: build, env, hosting, domain, SSL, rollback
- maintenance: updates, monitoring, backups, small fixes

Record as e.g.: `Classification: landing page + SEO + performance optimization`.

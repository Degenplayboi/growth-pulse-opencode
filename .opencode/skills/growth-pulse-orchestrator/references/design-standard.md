# Design Standard

Never produce generic AI-looking websites.

## Avoid by default
- generic purple/blue gradients, excessive glassmorphism
- meaningless floating cards, repetitive bento grids
- oversized meaningless text, random blobs, excessive rounded cards
- unnecessary animation
- fake testimonials, invented logos, invented partnerships, fake statistics
- copied brand identity, template-looking layouts

## Prioritize
- clear visual hierarchy, typography, spacing, composition
- brand personality, purposeful motion, meaningful interaction
- accessibility, responsive behavior, conversion, originality

## Rules
- Design references are research only; never copy.
- One clear primary CTA per view; secondary actions visually subordinate.
- Type scale + spacing must be consistent across breakpoints.
- Motion must have purpose (feedback, orientation, hierarchy). Respect reduced motion.
- Images / assets must be intentional, optimized, with alt text.
- Dark / light modes only when applicable and fully checked.

## Growth Pulse default
premium, modern, human, confident, conversion-focused, technically strong, fast, responsive, accessible, maintainable. Must feel deliberately designed by a professional team.

# Delivery Checklist

Produce this internally before final delivery. Only recommend handoff when all applicable items pass.

## REQUIREMENTS
- [ ] Client requirements satisfied
- [ ] No known missing requirements (or placeholders clearly listed)

## DESIGN
- [ ] Professional visual hierarchy
- [ ] Brand appropriate
- [ ] Not generic / template-like
- [ ] Mobile design considered
- [ ] Motion concrete: hover/tap response present; scroll reveal present on substantial work; reduced-motion respected
- [ ] No debug/comparison/attribution leakage in shippable pages
- [ ] Photographic assets tonally consistent with palette and adjacent text, confirmed per item

## FUNCTION
- [ ] Primary flows tested
- [ ] Forms tested
- [ ] Navigation tested
- [ ] Links tested

## QUALITY
- [ ] Accessibility checked
- [ ] Responsive behavior checked
- [ ] Console checked (no errors)
- [ ] Performance checked
- [ ] SEO checked when applicable
- [ ] Security checked when applicable

## DEPLOYMENT
- [ ] Production build verified
- [ ] Production URL verified
- [ ] Critical flows verified in production

If anything cannot be verified, mark `Not verified: <reason>` explicitly. Never invent test results, statistics, testimonials, or business claims.

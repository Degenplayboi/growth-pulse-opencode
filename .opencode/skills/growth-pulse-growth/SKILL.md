# Growth Pulse Growth

Leads + marketing + social + creative. This skill PREPARES; the human APPROVES;
sending/publishing/spending always waits. Fact labels follow
`growth-pulse-research`; delivery of client work stays with delivery skills.

## When to use

- Lead discovery, research, qualification, website audits, outreach drafts
- Marketing strategy, campaigns, content strategy, briefs, performance analysis
- Social content (X, LinkedIn, Facebook, Instagram, TikTok)
- Creative: static ads, variants, demos, short-form video, scripts, storyboards

## 1. Lead pipeline

```
DISCOVER → RESEARCH → VERIFY → QUALIFY → AUDIT → OPPORTUNITY → OUTREACH DRAFT
→ HUMAN APPROVAL → CONTACT → TRACK → FOLLOW UP → CONVERSATION → PROPOSAL
→ CLOSE → ONBOARD → DELIVER → RETAIN
```

- Record per lead (where legitimately available): company, website, industry,
  location, contact, source, actual observations, actual problems, opportunity,
  relevant service (must exist in `docs/business/services.md`),
  personalization angle, confidence, status, next action.
- Every field is VERIFIED (observed/fetched this session), REPORTED (source +
  date), or UNKNOWN. Never invent names, emails, problems, budgets,
  relationships, interactions, intentions, or stacks.
- Audit = real fetch/inspection of the prospect's public site (what loads,
  what breaks, what is missing) with URLs + dates. No fake audits.

## 2. Outreach

Relevant, truthful, personalized, concise, respectful, non-deceptive,
rate-limited, platform-compliant. Never pretend familiarity, never fabricate
research, never claim work not done. Drafts wait for APPROVE; follow-ups are
tracked in `docs/sales/`, never auto-sent.

## 3. Marketing manager

Research markets/competitors/offers/ads with evidence → campaign + content
strategy + briefs → analyze performance → opportunities + experiments.
Real numbers only; no invented results. Persist to `docs/marketing/`.

## 4. Social system

```
ACTIVITY → EVIDENCE → IDEA → PLATFORM VERSION → CREATIVE → APPROVAL
→ PUBLISH → MEASURE → LEARN
```

Show genuine work (screenshots, before/after, builds, lessons, real results).
No generic AI-quote pages. Platform-adapt each piece; approval before publish;
measure and write down what was learned.

## 5. Creative system

```
BRIEF → AUDIENCE → HOOK → PROBLEM → MECHANISM → PROOF → OFFER → CTA
→ STORYBOARD → CREATE → INSPECT → REVISE → APPROVE → PUBLISH
```

- Static ads, variants, demos, short-form, social creatives, before/after,
  resizing, captions, hooks, scripts, storyboards.
- Programmatic/branded video variants: prefer deterministic tools (e.g.
  Remotion) where appropriate. Do NOT claim image/video generation ability
  the connected provider lacks — state the gap and the tool needed.
- Inspect the artefact before revising; revise against the brief.

## Output

- Pipeline state or artefact (lead table, draft, brief, calendar, storyboard)
  + provenance per claim + files written + explicit APPROVAL request for any
  external send/publish/spend. Nothing consequential sent by the agent.

# growth-pulse-opencode

Growth Pulse OpenCode skills / instruction system — published for architecture and skill auditing.

- The skills under `.opencode/skills/` provide reusable project-wide behavior (routing, design, implementation, quality, deployment).
- `AGENTS.md` is the operating contract; `opencode.jsonc` is the runtime configuration.
- Treat these files as the current source of truth for review purposes.
- No application code, credentials, or secrets are included in this repository.
